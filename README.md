# 💼 OnlyJobs

A full-stack **job application tracker** built by CS students at Rutgers University at **HackRU**. Designed to simplify the overwhelming job search process by giving users a structured, clean platform to log and manage applications in one place.

---

## Features
- 🔐 **User Authentication** — Secure sign-up, sign-in via NextAuth
- 📋 **Job Tracking Dashboard** — Log applications with company, role, and status
- 🔄 **Status Management** — Applied → Interviewing → Offer → Rejected
- 🎨 **Clean UI** — Responsive interface with Framer Motion animations
- 🗄️ **Per-user isolated data** stored in MongoDB

---

## Tech Stack
| Layer | Technology |
|---|---|
| Frontend | Next.js 15, React 19, TypeScript |
| Styling | Tailwind CSS |
| Auth | NextAuth.js |
| Database | MongoDB + Mongoose |
| Animation | Framer Motion |

---

## Getting Started
```bash
git clone https://github.com/Meetpatil9822/OnlyJobs.git
cd OnlyJobs/HackRu-main
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the app.
